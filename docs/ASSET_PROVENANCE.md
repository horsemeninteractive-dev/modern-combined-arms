## What is already solid

- The ambience set has a complete CC0 credit table with authors and source URLs.
- The two narrator voices have a documented recording provenance and are treated
  as fixed assets, not regenerated by the Kokoro pipeline.
- The unit-voice pipeline records its model (`kokoro-82m-onnx`), version,
  processing settings and per-cue manifest.
- The repository has a top-level MIT licence for the code.

## Decisions still needed

1. **Confirm the Suno plan and commercial terms** for all six music tracks. If
   the account does not grant the intended distribution rights, replace the
   tracks or obtain a written licence.
2. **Confirm TTSMaker and ElevenLabs terms** for the narrator recordings,
   including redistribution in a game build and promotional media.
3. **Record flag sources** and whether each image is public domain, licensed or
   project-created.
4. **Record font licences** and include the licence text next to the fonts; if a
   font cannot be cleared, replace it.
5. **Separate the asset licence from the code licence.** Once the above are
   confirmed, add an asset licence/notice file and link it from `LICENSE` and the
   README.

Until those are closed, this ledger is an inventory and a blocker list, not a
claim that every shipped asset is cleared for public distribution.
